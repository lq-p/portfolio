AI virtual customer representative

A real-time, AI-powered virtual customer representative for a Turkish participation bank, built end to end over a two-month placement.

Case details

Organisation
Kuveyt Türk Participation Bank (Architecht)
Role
Software Engineering Intern
Disciplines
  • System architecture
  • Frontend and backend development
  • API integration
  • Performance and latency testing

Architecht is the technology arm of Kuveyt Türk Participation Bank. Over a placement in Pendik I built a real-time, AI-powered virtual customer representative — the same category of system as Selim, the digital assistant inside the bank’s own mobile application.

I ran the project end to end: the system architecture, the frontend and the backend, the API integration between them, and the optimisation pass that followed. Because the thing had to hold a conversation, latency was the metric that mattered most, so a large part of the work was performance testing — measuring where the round trip actually went and cutting it down until the exchange felt immediate rather than transactional.

Interns at Architecht were eligible to work remotely. I chose to work on site for the full placement, eight to five, on the same footing as the developers around me — the point of the placement was the room, not the ticket queue.
